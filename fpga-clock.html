FPGA Digital Clock

Digital systems · FPGA designDec 2024

Team course project · Logic Design and Laboratory

Co-developed a multifunction digital clock in Verilog and implemented it on a Basys 3 FPGA using Xilinx Vivado. The system integrates timekeeping, editable time and alarm settings, a centisecond stopwatch, and an LED-based game for dismissing the alarm.

Project goal

Build an interactive digital system using the board’s switches, pushbuttons, LEDs, and four-digit seven-segment display. The design combines synchronous timing and stored settings with mode control and physical user inputs.

Core idea: coordinate independent functions through a shared display

The top-level design integrates separate time-setting, timekeeping, alarm-setting, stopwatch, and alarm-game modules. It selects the active module’s segment and digit-enable signals for the shared display, giving the alarm/game path priority over normal operating modes.

Implementation highlights

Timing and display: Counter logic driven by the 100 MHz board clock provides the timekeeping, stopwatch, and digit-scan timing. Multiplexing activates one display digit at a time.

Physical inputs: The alarm-setting and stopwatch paths use button debouncing and edge detection. The game inputs pass through two-stage synchronizers before switch-response evaluation.

Alarm game: An LFSR-based sequence selects among ten LEDs for timed, two-second response windows. The game tracks the score, rejects invalid switch responses, and releases the display back to normal operation after three correct responses.

Project outcome

Completed the clock, setting modes, stopwatch, and alarm-dismissal game as an integrated FPGA course project. The work provided hands-on experience with Verilog module integration, synchronous counters, input handling, display multiplexing, and board-level I/O constraints.
